# Browser Router spec

- macOS 14.0+ ネイティブアプリ
- デフォルトブラウザとして登録し、http/https URLを受け取る
- HTML ドキュメント (html, xhtml, url) のファイルオープンも受け取る
- URL受信時にウィンドウが自動的に表示される

## ウィンドウ

- メインウィンドウは常に最前面、全Spacesに表示
- リサイズ・最小化可能。最小サイズ 300x150
- タイトルバーにバージョン表示 ("Browser Router vN.0.0")
- 設定ウィンドウは最前面、リサイズ不可、既存インスタンスを再利用

## Dock / メニューバー

- ウィンドウが開いている間だけDockに表示。全て閉じるとDockから消える
- Dockアイコンクリックでウィンドウ再表示
- メニューバーにglobeアイコンを常時表示: Show Window / Settings / Quit

## メニュー / キーボードショートカット

- Cmd+W: ウィンドウを閉じる
- Cmd+Q: アプリ終了
- Cmd+C: コピー
- Cmd+A: 全選択
- Cmd+,: 設定を開く
- About Browser Router: Aboutパネルを表示

## ブラウザ検出

- https を開けるアプリを自動検出し、自アプリを除外して一覧表示
- ブラウザ名から `.app` を除去

## URL表示

- 新しいURLが上に来る
- 新着URLは3秒間ハイライト（アクセントボーダー+背景）、自動スクロール
- タイムスタンプ (時刻) 表示
- URL表示は設定行数で打ち切り、中央省略
- URLにホバーするとツールチップで全文表示
- URL間にセパレータ線
- フォントは等幅

## アクション

- Copy ボタンと各ブラウザボタンがURLごとに並ぶ
- ボタンはフローレイアウトで、横に溢れたら次の行に折り返す
- Copy: クリップボードにコピー。1.5秒間「Copied!」表示
- ブラウザボタン: 該当ブラウザでURLを開く。ホバーでブラウザ名のツールチップ
- アイコンのみモードではブラウザボタンがアイコンだけになるが、ツールチップでブラウザ名が出る
- autoCloseOnAction 有効時、アクション実行後にウィンドウを閉じる

## ウィンドウクローズ時

- copyOnClose 有効時、最新URLをクリップボードにコピーする。ただしアクション経由のクローズでは発動しない
- clearOnClose 有効時、全URL履歴をクリア

## 設定

- General: デフォルトブラウザかどうかを表示。デフォルトでなければ「Set as Default」ボタンでシステム設定を開く
- Behavior:
  - アイコンのみモード (default: off)
  - ウィンドウクローズ時に履歴クリア (default: off)
  - アクション後に自動クローズ (default: off)
  - Escキーでクローズ (default: off)。メインウィンドウがキーウィンドウのときのみ
  - フォーカス喪失時にクローズ (default: off)
  - クローズ時に最新URLコピー (default: off)
- Appearance:
  - URL表示行数 (default: 2, range: 1-10, stepper)
  - UIスケール (default: 100%, range: 70%-400%, step: 10%, slider)
  - ウィンドウ幅 (default: 600, range: 300-1200, step: 50, slider)
  - ウィンドウ高さ (default: 300, range: 150-800, step: 50, slider)
- Hidden Browsers: 個別のブラウザを非表示/再表示
- フッターにバージョンとコミットハッシュを表示
- 全設定は即時永続化。ウィンドウサイズはスライダー操作時にリアルタイムアニメーション反映

## ビルド・インストール

- `build.sh` でビルド+ad-hoc署名
- `install.sh` で /Applications/ にインストール
- バージョンは単一の自然数。表示は N.0.0 形式
- コミットハッシュがAboutパネルと設定フッターに表示される
